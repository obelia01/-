#小皮面板陆口获取
获得小皮桌面登陆口

# 介绍
小皮面板为了后台安全，防止被Web后台被暴力破解，在启动服务时会生成一个6位小写字符跟数字组成的随机路由来保护后台登陆地址。需要先访问安全入口获取对应的Cookie后才会被允许访问到登陆路径/login
